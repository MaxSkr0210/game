# Neon Mask

Top-down шутер в духе Hotline Miami. Открой папку `game` как Unity-проект (2022.3 LTS или Unity 6) и нажми Play.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD / стрелки |
| Прицел | Мышь |
| Стрельба / удар без оружия | ЛКМ |
| Ближний бой | ПКМ / F |
| Бросить оружие | Q / G |
| Подобрать / сменить | E (пусторукий подбирает сам) |
| Рестарт | R / Space |

## Как играть

Ты и враги умираете с одного попадания. Начинаешь с кулаков — сними первого с ножом или вплотную, забери пистолет/узи/дробовик и зачисти здание. Враги патрулируют, видят конусом и слышат выстрелы. Цель: убить всех.

Спрайты и звуки собираются в рантайме, сторонние ассеты не нужны.
